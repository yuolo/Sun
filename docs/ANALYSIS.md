# Анализ 2.0

Первая версия (см. [v1/](v1/)) доказала формулу: знаки без перевода, догадки в дневнике, страницы подтверждения — и настоящий язык вместо выдуманного. Она была короткой (51 знак, ~1 час) и держалась на механике расшифровки. Вторая версия отвечает на отзыв:

| # | Запрос | Что из этого следует |
|---|---|---|
| 1 | Стилистика Pyxel, сам Pyxel как библиотека | Переписать игру на Python + Pyxel: пиксель-арт, ограниченная палитра, чиптюн |
| 2 | Предметы тоже на китайском: иконка + знак, чтобы запоминать | Названия вещей — иероглифами, с картинкой; отдельный канал запоминания |
| 3 | Непонятно, почему я путешествую и зачем | Личная история с целью, сроком и развязкой |
| 4 | Нравятся диалоги с людьми, нужны разные языковые головоломки | Больше разговорных механик и каталог из ~15 типов задач |
| 5 | Не меньше 1000 разных иероглифов | Масштаб × 20: слои обучения, данные, автоматические страницы |
| 6 | Словесная магия: заклинание — комбинация иероглифов | Язык становится инструментом действия; грамматика — механикой |

Ниже — разбор каждого пункта и принятые решения. Подробности сюжета и мира — в [GAME_DESIGN.md](GAME_DESIGN.md), этапы — в [PLAN.md](PLAN.md).

## 1. Pyxel

### Что это
[Pyxel](https://github.com/kitao/pyxel) — ретро-движок на Python (ядро на Rust). Его ограничения и есть его стиль:

- **Палитра.** 16 цветов по умолчанию (можно расширить), никаких градиентов и полупрозрачности — только сплошные цвета и **дизеринг** (`pyxel.dither`).
- **Низкое разрешение.** Обычно до 256×256. Чёткие квадратные пиксели, увеличение целым масштабом.
- **Банки картинок и тайлмапы.** 3 банка 256×256 + любое число `Image`, 8 тайлмапов, спрайты с прозрачным цветом, отражение, поворот, масштаб.
- **Звук.** 4 канала, тембры треугольник / квадрат / пульс / шум, эффекты, MML-нотация, `gen_bgm`. Экспорт в WAV.
- **Шрифты.** Встроенный 4×6 (только латиница) + свои BDF/TTF/OTF — это важно для китайского и русского.
- **Платформы.** Windows / macOS / Linux, **веб** (Pyodide + `pyxel.js`, команда `pyxel app2html`), пакет `.pyxapp`, исполняемые файлы.
- **Headless-режим** (`pyxel.init(..., headless=True)`), подстановка ввода (`set_btn`, `set_mouse_pos`, `set_input_text`), `input_text` для ввода текста — всё это даёт автотесты и скриншоты без окна.

### Проверено в контейнере (Pyxel 2.9.9)
- Шрифт **Fusion Pixel 12px** (OFL 1.1) через `pyxel.Font(ttf, 12)` рисует упрощённые иероглифы и кириллицу чётко, пиксель в пиксель.
- Палитру можно расширить до 32+ цветов (`pyxel.colors[:] = [...]`).
- Headless-рендер и сохранение кадра в PNG работают — так будут проверяться сцены.
- `pyxel.input_text` отдаёт набранный текст (для догадок на русском).

### Решение: переписать игру на Pyxel
Игра переходит с TypeScript/SVG на **Python 3.11 + Pyxel 2.9**. Причины: это прямая просьба; ограничения Pyxel дают цельный стиль без компромиссов «псевдопиксель поверх векторов»; headless-режим позволяет тестировать и снимать каждую сцену; MML даёт честный чиптюн. Интерфейс (дневник, карточки, головоломки) тоже рисуется пикселями — так выглядит цельнее, чем HTML поверх канваса.

| Что теряем | Как компенсируем |
|---|---|
| Web Speech (озвучка) доступен только в браузере | В веб-версии вызываем `speechSynthesis` через мост Pyodide `js`; на десктопе озвучки нет, пиньинь остаётся |
| Artifact на claude.ai не запустит Pyodide с `jsdelivr.net/gh` (политика скриптов) | Раздача: GitHub Pages (`app2html` в CI), файл `.html` (нужен интернет), `.pyxapp` для `pyxel play`, исполняемые файлы |
| В контейнере закрыт `jsdelivr`, веб-сборку нельзя прогнать здесь | Вся логика и отрисовка проверяются в headless-режиме; веб-специфика изолирована в одном модуле с запасными вариантами |
| Сохранения в браузере | `localStorage` через `js`; на десктопе — JSON в `pyxel.user_data_dir` |

### Стиль, который берём у Pyxel
- **Экран 320×180** (16:9, масштаб ×4 → 1280×720, ×6 → 1920×1080), 30 кадров/с.
- **Палитра 32 цвета**: 16 базовых цветов Pyxel + 16 «китайских» (киноварь, нефрит, охра, тушь, золото, туман, ночная синь). Время суток — **подменой палитры** (`pyxel.pal`), как в играх 80-х: одна и та же сцена днём, на закате, ночью, перед рассветом.
- **Дизеринг** для неба, тумана, света фонаря, облаков.
- Люди — спрайты ~12×28 px с 2–4 кадрами ходьбы; предметы и иконки — 16×16.
- Анимированные слои: вода, огонь, облака, дождь, светлячки, чернила заклинаний.
- **Шрифты:** Fusion Pixel 12px для иероглифов и русского текста; свой мини-шрифт 5×7 для догадок под знаками; крупный знак в карточке — растр LXGW WenKai (кисть), чтобы были видны черты.
- **Звук:** пентатоника (宫 商 角 徵 羽) на треугольнике (флейта), квадрате с затуханием (щипковые, как гучжэн), шуме (деревянная рыбка 木鱼, барабан).

## 2. Предметы на китайском

В v1 вещи назывались по-русски («Ведро», «Фонарь»). Это упущенный канал: предмет — самая наглядная подсказка к знаку.

- У каждого предмета **иконка 16×16 и название иероглифами** (灯, 伞, 桶, 票…). Русского названия нет, пока знак не подтверждён; под знаком видна ваша догадка, как везде.
- Получая предмет, игрок видит карточку «иконка + знак», а персонаж, который его дал, **называет его вслух**.
- **Показать предмет** человеку → он его называет («伞！»). Так учатся названия вещей без перевода.
- Кроме инвентаря (~40 вещей) — **подписанный мир**: товары на рынке с ценниками, меню, вывески лавок, букварь 看图识字 в деревенской школе. Это ~250 конкретных существительных с картинками.
- Подтверждение — **страницы с иконками** (как в CoS: картинка + пустая клетка), собранные автоматически по темам: еда, животные, инструменты, одежда, тело, природа, дом.

## 3. Зачем я иду: сюжет

В v1 цель («увидеть восход») была декорацией. Нужна личная причина, срок и развязка. Рассмотрены три варианта:

| Вариант | Плюсы | Минусы |
|---|---|---|
| А. Письмо деда (реализм) | Личная мотивация, эмоция, понятная русскоязычному игроку | Сложно оправдать магию |
| Б. Чистая сказка (солнце перестало всходить) | Эпический масштаб, магия естественна | Холодно, нет личной связи |
| **В. Магический реализм** | Личная история деда + гора, на которой написанные слова оживают | Нужно аккуратно ввести магию — через легенды самой горы |

**Выбран вариант В.** Кратко: в 1958–1960 годах дед работал в Китае инженером на мосту у подножия Тайшаня. Его другом стал носильщик Ли Мин (李明): учил его иероглифам и дал на время семейную кисть. Друзья поднялись на гору встречать восход, но шёл дождь, солнца не было. Они договорились вернуться в день осеннего равноденствия (秋分). Летом 1960 года советских специалистов внезапно отозвали, и дед уехал, не простившись. Кисть так и осталась у него. После смерти деда вам достаются кисть, его дневник на китайском (он учил язык всю жизнь) и неотправленное письмо Ли Мину. Вы едете вернуть кисть, отдать письмо и встретить рассвет за двоих. Ли Мину 88 лет, и каждое 秋分 он поднимается на пик Созерцания солнца. Шестьдесят лет подряд вершина в этот день закрыта облаками.

Что это даёт игре:
- **Цель и срок.** Успеть на вершину к рассвету; вся игра — один день и одна ночь (от золотого часа до восхода), как и в v1.
- **Причина учить язык внутри истории.** Дед просит не пользоваться переводчиком («он не поймёт главного»), а кисть слушается только того, кто *понимает* знаки.
- **Параллельное чтение.** Дневник деда описывает те же места, куда вы приходите. Он писал его, пока учился, поэтому первые записи простые, а последние сложные — его путь повторяет путь игрока.
- **Развязка — чтение.** В финале вы читаете письмо вслух Ли Мину и получаете его ответ, написанный в 1960 году. Последний текст игры становится понятен благодаря всему выученному.

## 4. Разговоры и языковые головоломки

Диалоги — сильная сторона v1. Расширяем глаголы разговора:

- **Слушать и отвечать** (было): составить ответ из знаков.
- **Показать предмет** (новое): человек называет вещь, реагирует, просит или отказывается.
- **Спросить о знаке** (новое): выбрать знак в дневнике → человек читает его вслух (озвучка), у сюжетных знаков особые ответы (李明, 中天门, 日出).
- **Письменный разговор 笔谈** (новое): с монахиней, давшей обет молчания, можно только переписываться. Так в старину говорили японцы и корейцы с китайцами, не зная устной речи.
- **Торг, указания дороги, перекличка носильщиков, загадки, парные надписи** — см. каталог.

Каталог головоломок (подробно — в GAME_DESIGN, §6):

| Тип | Чему учит |
|---|---|
| Ответ из знаков | Порядок слов, вопрос/ответ, 吗 |
| Заказы в чайной (поднос) | Числа, 大/小, 杯/碗 |
| Меню с бюджетом | Названия еды, цены, сложение |
| Торг | Числа, 太贵了, 便宜, 不/好 |
| Список носильщика | Счётные слова: 三把伞, 两双鞋, 五本书 |
| Бюро находок | Цвета и признаки: 红 黄 蓝 大 小 长 新 旧 |
| Дорога в тумане | 左 右 前 后 上 下 东 西 南 北 |
| Письменный разговор 笔谈 | Чтение вопросов, ответ письмом |
| Перекличка носильщиков 号子 | Ритм и повтор, запоминание на слух |
| Загадки о знаках 字谜 / 灯谜 | Устройство знака: 一口咬掉牛尾巴 → 告 |
| 虫二 — настоящая загадка на Тайшане | Упрощённые и полные формы: 風月 без краёв |
| Парные надписи 对联 | Антонимы и параллелизм: 天↔地, 日↔月, 上↔下 |
| Колокола (было) | Последовательность, 雨 云 月 |
| Сборка знаков из частей (было) | 日+月=明, 人+木=休, 日+一=旦 |
| Древние формы (было) | Пиктограммы 甲骨文 |
| Переписывание надписей 符 | Отрицание, порядок слов, антонимы (см. §6) |
| Заклинания кистью | Составные слова, грамматика (см. §6) |

## 5. Тысяча иероглифов

### Какие знаки
Опора — стандарт HSK 3.0 (GF 0025-2021): уровни 1–3 — это ровно 900 самых нужных знаков. К ним добавляются ~200 знаков истории: места Тайшаня (泰 岱 岳 碧 霞 祠 峰 盘 松), легенды, еда и вещи. **Цель — ≥1100 разных знаков** (запас сверх требования 1000); проверка — автоматический тест.

### Где живут тексты
Один лишь сюжетный диалог в 1000 знаков не уложится: чтобы набрать тысячу *разных* знаков, нужно ~12–15 тыс. знаков текста. Поэтому текст распределён по жанрам — каждый даёт свои слова:

| Источник | Объём | Что даёт |
|---|---|---|
| Диалоги (~60 персонажей) | ~5000 знаков | Разговорная речь, частицы, вопросы |
| Дневник деда (~40 записей 1958–1960 и позже) | ~5000 | Быт, погода, работа, чувства, время, история дружбы |
| Письма (деда и ответ Ли Мина) | ~500 | Эмоциональная развязка |
| Вывески, стелы, надписи на скалах, парные надписи | ~1000 | Названия мест, классика (杜甫 «望岳», 五岳独尊) |
| Товары, ценники, меню, букварь | ~800 | Конкретные существительные с картинками |
| Легенды (книга в чайной, рассказчик) | ~1500 | 仓颉造字, 神笔马良, 画龙点睛, 后羿射日, 石敢当 |
| Книга заклинаний | ~300 | Составные слова и идиомы |

### Как выучить тысячу, а не утонуть
Расшифровывать по методу CoS тысячу знаков нереально. Поэтому обучение слоистое:

1. **Ключевые знаки (~170).** Классическая CoS-расшифровка: контекст → догадка → иллюстрированная страница. Нужны для прохождения.
2. **Вещи (~250).** Иконка + знак (предметы, товары, букварь, образы заклинаний). Подтверждаются **страницами с иконками**, собранными автоматически по темам.
3. **Знаки из контекста (~700).** Подтверждаются **страницами-строками**: 4–5 фраз, которые вы слышали или читали, в каждой пропущен один знак; разложите знаки по пропускам. Страница засчитывается, только если всё верно (правило CoS). Фразы и группы подбираются автоматически: в одной странице — знаки из разных смысловых полей, чтобы их нельзя было перепутать. Результат генерации проверяется тестом и вручную.
4. **Подсказки масштаба.** Карточка знака показывает все фразы, где он встречался, из каких частей состоит (ключ 氵 — «вода», 讠 — «речь»…) и какие знакомые слова с ним есть. Люди читают знак вслух. Заклинание кистью показывает «тень» смысла (см. §6).

**Для прохождения нужно ~300 знаков.** Остальные — глубина: дочитать дневник деда, стелы, легенды. Полностью подтверждённая запись дневника открывает «понимание» — пересказ по-русски, как награду за чтение.

### Данные
- **Пиньинь** — `pypinyin` (MIT) на этапе сборки, с учётом многозначных чтений в словах (行 háng/xíng, 长 cháng/zhǎng).
- **Ключи, состав, частотность** — данные npm-пакета `hanzi` (MIT; разложения cjk-decomp, частотность Цзюнь Да). CC-CEDICT — только как справка при написании русских значений, в игру не входит.
- **Русские значения, часть речи, смысловое поле, эффект в магии** — пишутся вручную в `data/hanzi.tsv` (~1100 строк); сборочный скрипт объединяет всё в модуль данных, тесты проверяют полноту.

## 6. Словесная магия

### Идея
На священной горе написанное становится явью — 言出法随 («слово сказано — закон следует»). Магия опирается на настоящие легенды: 仓颉造字 (когда Цан Цзе создал письмо, «небо пролилось зерном, а духи плакали ночью»), 神笔马良 (волшебная кисть Ма Ляна), 画龙点睛 (дракон ожил, когда ему дорисовали зрачки). Кисть Ли Мина пишет **живые знаки**, но «дорисовать зрачки» знаку можно, только если его **понимаешь**. Так изучение языка становится силой.

### Две формы
**1. Письмо кистью (咒).** Кисть в интерфейсе: выбираете знаки из дневника (1–4, у идиом до 6), цель (человек, предмет, место, воздух) — знаки вспыхивают чернилами, черта за чертой.

| Конструкция | Пример | Эффект |
|---|---|---|
| Существительное | 火, 鱼, 花 | Образ вещи: пламя, рыба, цветок (живёт несколько секунд) |
| Число + счётное + сущ. | 三条鱼 | Три рыбы; без счётного слова образ дрожит, с чужим (三本鱼) выходят «рыбы-книжки» |
| Прилаг. + сущ. | 大火, 红花 | Образ со свойством |
| Прилаг. на цель | 红 → фонарь, 大 → камень | Цель меняется: цвет, размер, свет, температура |
| Глагол на цель | 笑 → стражник, 睡, 跳, 飞, 开 | Действие: смеётся, засыпает, подпрыгивает, парит, открывается |
| Подлежащее + сказуемое | 门开, 雨停, 云开, 花开 | Утверждение становится правдой (если это возможно здесь) |
| 不 / 很 / 太 + … | 不冷, 很大, 太大 | Отрицание снимает, 很 усиливает, 太 — перебор с комичным сбоем |
| Составное слово | 火山, 山水, 东西, 开心, 小心 | Особые эффекты; учат, что смысл слова ≠ сумма частей (东西 = «вещь») |
| Идиома 成语 | 画龙点睛, 水落石出, 风吹云开 | Сильные сюжетные заклинания, найденные в мире |
| Сборка знака | 日+月 → 明, 人+木 → 休 | Новый знак — новое заклинание (свет, отдых) |

**2. Переписывание надписей (符).** На горе висят талисманы и надписи, которые *уже* действуют: «门不开» держит дверь запертой, «水大» поднимает ручей. Кистью можно убрать, вставить или переставить знак — мир меняется вслед за текстом. Механика в духе *Baba Is You*: отрицание (门不开 → 门开), антонимы (水大 → 水小), порядок слов (门天南 → 南天门), замена (雨 → 晴).

### Правила баланса
- **Сила = понимание.** Подтверждённые знаки пишутся в полную силу. Встреченные, но не подтверждённые — «тенью»: образ вещи мелькает полупрозрачно и мир не меняется. Это инструмент проверки догадки («я думаю, 鱼 — птица… пишу — появляется рыба»).
- **Образы исчезают.** Магия не создаёт постоянных предметов и не заменяет торговлю и разговоры.
- **Воля людей неприкосновенна.** Глаголы настроения (笑, 睡) дают короткую смешную реакцию. Люди отвечают словами («哇！神笔！», «不要！»), а это — новые фразы для словаря.
- **Несколько решений.** Многие задачи решаются и разговором, и кистью (ведро можно наполнить у реки или написать 水); сюжетные узлы требуют именно понимания грамматики.
- **Книга заклинаний** в дневнике: открытые формулы, их эффект и счётчик (≈120 заклинаний).

### Почему это учит
Магия заставляет *производить* язык, а не только узнавать его: знать смысл, порядок слов (门开 и 开门 работают, 门火 — нет), роль 不/很/太, счётные слова, составные слова. Ошибка не наказывается, а показывает, что не так. Эксперимент вознаграждается открытием.
