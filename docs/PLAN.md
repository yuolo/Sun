## Архитектура

```
index.html
src/
  main.ts                 точка входа: меню, запуск игры
  core/                   логика без DOM (покрыта тестами)
    types.ts              типы состояния, сцен, скриптов
    state.ts              состояние игры, сохранение/загрузка, миграции
    journal.ts            увиденные знаки, догадки, подтверждение страниц, заметки
    phrases.ts            разбор фраз на знаки, сопоставление ответов
    puzzles.ts            логика подноса, колоколов, составления знаков
    hints.ts              подсказки по состоянию
    numerals.ts           числа ↔ китайская запись
  content/                данные игры
    lexicon.ts            51 знак: пиньинь, значение, заметки
    pages.ts              страницы подтверждения
    grammar.ts            грамматические заметки
    items.ts              предметы
    chapters/ch1..ch4.ts  сцены, персонажи, скрипты
  ui/                     отображение (DOM + SVG)
    stage.ts              сцена 16:9, масштабирование, слои
    scene-runtime.ts      ходьба по пути, персонажи, клики, реплики → реализация ScriptContext
    bubbles.ts            реплики с кликабельными знаками и подписями-догадками
    journal-ui.ts         дневник: знаки, страницы, записи, грамматика
    popover.ts            карточка знака: догадка / значение / пиньинь / звук
    composer-ui.ts        составление ответа
    puzzles-ui.ts         поднос, колокола, составление знаков, стела
    menu.ts               титульный экран, пауза, настройки, финал, повторение
    audio.ts              озвучка (Web Speech), музыка и звуки (Web Audio)
    fx.ts                 дождь, облака, ночь и свет фонаря
  art/                    процедурная SVG-графика
    palette.ts            палитры времени суток
    kit.ts                горы, туман, сосны, дома, ворота, ступени, стелы...
    figures.ts            персонажи
    illustrations.ts      картинки для страниц подтверждения
    ancient.ts            древние формы пиктограмм
  styles/main.css
public/fonts/             шрифты-подмножества (woff2)
scripts/subset-fonts.py   генерация подмножеств шрифтов из лексикона
tests/                    Vitest: логика, целостность контента, полное прохождение
```

**Ключевой принцип:** скрипты сцен пишутся против интерфейса `ScriptContext` (`say`, `give`, `ask`, `puzzle`, `goto`…). В игре его реализует UI (с анимациями), в тестах — «безголовый» контекст. Это позволяет автоматически пройти игру целиком и доказать отсутствие тупиков.

## Как проверяем

| Что | Как |
|---|---|
| Логика | Vitest, модульные тесты |
| Целостность контента | Тест: все иероглифы сценария ∈ лексикон; каждая страница состоит из знаков лексикона; каждый знак подтверждаем; все переходы ведут в существующие сцены |
| Отсутствие тупиков | Тест: скриптовое прохождение от 1a до восхода через `ScriptContext` |
| Вёрстка и графика | Скриншоты Playwright на 1600×900 и 390×844 |
| Типы | `tsc --noEmit` в strict-режиме |
