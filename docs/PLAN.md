# План 2.0

**Статус:** все этапы выполнены. 30 сцен, 745 знаков, все 601 слово HSK 1–3 встречаются за один проход (проверяет тест),
вся игра проходится через настоящий интерфейс (`scripts/e2e.py`), сборка для браузера — `scripts/build_web.py`.

Основа — [ANALYSIS.md](ANALYSIS.md) (почему так) и [GAME_DESIGN.md](GAME_DESIGN.md) (что делаем). План v1 — в [v1/PLAN.md](v1/PLAN.md).

## Архитектура

Игра переехала с TypeScript/SVG на **Python 3.11 + Pyxel 2.9**. Версия v1 удалена из дерева на этапе 10 и остаётся в истории git.

```
pyproject.toml              зависимости (pyxel, pypinyin для сборки, pytest)
richu/                      пакет игры
  __main__.py               python -m richu
  platform.py               веб или десктоп: сохранения (localStorage / файл), озвучка (speechSynthesis / нет)
  engine/                   тонкий слой над Pyxel
    app.py                  инициализация, главный цикл, стек экранов
    tasks.py                исполнитель скриптов-корутин (await c.say(...)) без asyncio
    text.py                 шрифты, раскладка знаков с подписями-догадками, перенос
    ui.py                   панели, кнопки, списки, прокрутка, подсказки
    audio.py                MML-музыка и звуки
  core/                     логика без Pyxel (покрыта тестами)
    types.py state.py journal.py pages.py phrases.py numerals.py
    magic.py                разбор и применение заклинаний
    talisman.py             переписывание надписей
    puzzles.py hints.py review.py
    headless.py             контекст скриптов для тестов и автопрохождения
  content/                  данные игры
    lexicon/                ~700 знаков по главам: пиньинь, значение, происхождение, слова, теги
    hsk.py                  слова HSK 1–3 (сгенерировано)
    hanzi_meta.py           состав знаков и частотность (сгенерировано)
    items.py spells.py pages.py grammar.py hints.py world.py
    texts/                  дневник деда, письма, надписи, легенды, товары
    chapters/               пролог, главы 1–6: сцены, персонажи, скрипты
  art/                      процедурный пиксель-арт
    palette.py              32 цвета и подмены палитры по времени суток
    kit.py                  небо, хребты, сосны, ступени, арки, крыши, вода, туман…
    figures.py              люди: одежда, головные уборы, предметы, ходьба
    icons.py                иконки 16×16 (ASCII-спрайты)
    scenes/                 рисунки сцен
    fx.py                   дождь, туман, огонь, чернила кисти, образы
  ui/                       экраны и окна
    scene_view.py           сцена: ходьба, клики, реплики → реализация ScriptContext
    hud.py bubbles.py card.py composer.py brush.py talisman_ui.py
    journal/                знаки, страницы, тексты, фразы, заклинания, грамматика, повторение
    puzzles/                поднос, колокола, торг, список, находки, туман, перекличка, парные надписи, загадки…
    menus.py map.py
assets/fonts/               подмножества шрифтов (Fusion Pixel 12px, мини-шрифт, LXGW WenKai) + OFL
scripts/                    сборка данных и шрифтов, скриншоты сцен, веб-сборка
tests/                      pytest
```

**Ключевой принцип сохраняется из v1:** скрипты сцен написаны против интерфейса `ScriptContext` (`say`, `ask`, `give`, `cast`, `puzzle`, `goto`…). В игре его реализует `ui/scene_view.py` с анимацией, в тестах — `core/headless.py`. Поэтому игру можно пройти автоматически от пролога до восхода.

## Как проверяется результат
- `pytest` — логика, магия, целостность контента (покрытие HSK 1–3, подтверждаемость, переходы сцен, предметы, заклинания), автопрохождение.
- `python scripts/shots.py` — снимок каждой сцены и окна в headless-режиме для ручного просмотра.
- `python -m richu` — ручная игра на десктопе; `pyxel app2html` — веб-версия.
