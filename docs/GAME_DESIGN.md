# 日出 · Восход — дизайн игры

> Путник из далёких земель поднимается на гору Тайшань, чтобы встретить рассвет на Пике созерцания солнца.
> Он не знает языка — но у него есть дневник.

## 1. Концепция

- **Жанр:** point-and-click приключение-расшифровка (как Chants of Sennaar).
- **Цель игрока:** подняться от подножия Тайшань до Пика созерцания солнца (日观峰) и увидеть восход.
- **Цель обучения:** ~50 иероглифов, базовая грамматика, пиньинь и тоны.
- **Время:** ≈ 1–1,5 часа. Сцена — один экран 16:9, ходьба по клику.
- **Время суток идёт вместе с подъёмом:** золотой день у подножия → закат у Красных ворот → сумерки, дождь и ночь в середине пути → ночь на вершине → восход.

## 2. Основные механики

| Механика | Описание |
|---|---|
| Реплики и надписи | Все реплики NPC и надписи — только иероглифы. Любой знак кликабелен. |
| Дневник (笔记) | Все увиденные знаки. Клик по знаку → поле догадки. Догадки подписываются под знаками в репликах и на вывесках. |
| Страницы подтверждения | Страница открывается, когда увидены все её знаки. Разложи знаки по рисункам; засчитывается только если всё верно. Подтверждённый знак получает значение, пиньинь (цвет = тон), озвучку, заметку о происхождении. |
| Записи | Журнал всех услышанных фраз — чтобы сравнивать шаблоны. |
| Ответ (составление фразы) | Некоторые NPC задают вопрос — игрок собирает ответ из увиденных знаков. |
| Предметы | Небольшой инвентарь: ведро, дрова, лучина, фонарь, поднос. Предмет применяется к персонажу/объекту. |
| Головоломки | Поднос с заказами (числа, 大/小, 茶/水), колокола (знак ↔ картинка), составление иероглифов из частей. |
| Грамматические заметки | Открываются после подтверждения ключевых знаков. |
| Повторение | Карточки-викторина по подтверждённым знакам (из меню и дневника). |
| Подсказки | Необязательные, постепенные, на русском. |

## 3. Главы и сцены

### Глава 1. 山下 — «У подножия» (день, золотой свет)

**Знаки (13):** 你 好 我 要 水 火 木 不 谢 山 上 下 吗

| Сцена | Что есть |
|---|---|
| **1a Пристань** | Лодочник; река (набрать воду). |
| **1b Деревня** | Женщина у пустого чана; старик у погасшего костра; человек с тёмным фонарём; поленница; ведро. |
| **1c Арка начала пути (岱宗坊)** | Указатель «上山 / 下山»; стражник; носильщик (挑山工) и спускающийся паломник разыгрывают сценку. |

**Сценарий:**

- Лодочник: `你好！` → `你好！你上山吗？`
- Женщина: `我要水。` · ведро с водой → `好！谢谢！谢谢！` (даёт 3 монеты) · не то → `不要X。我要水。`
- Старик: `我要木。` · дрова → костёр загорается: `好！火！谢谢。` (от костра можно взять лучину) · не то → `不要X。我要木。`
- Человек с фонарём: `我要火。` · лучина → `谢谢！` (дарит зажжённый фонарь) · не то → `不要X。我要火。`
- Лучина гаснет, если уйти из деревни.
- Сценка у арки (при первом входе): стражник `你上山吗？` — носильщик `上山。` — стражник `好。` (носильщик уходит вверх); паломник спускается: `你好！` — стражник `你好！下山吗？` — паломник `下山。`
- Стражник игроку: `你上山吗？` → **ответ**: `上` / `上山` / `我上山` / `我要上山`.
  - Без фонаря: `上山…要火。` · с фонарём: `好！` → глава 2.
  - Ответ с 不: `不上山？好。`

**Страницы:** «Стихии» 山 水 火 木 · «Люди» 你 我 好 谢 · «Путь» 上 下 要 不 吗

### Глава 2. 红门 — «Красные ворота» (закат)

**Знаки (20):** 一 二 三 四 五 六 七 八 九 十 两 几 杯 茶 大 小 钱 有 没 人

| Сцена | Что есть |
|---|---|
| **2a Рынок** | Дети играют в «классики» и считают `一`…`十` (по знаку на каждый прыжок). Уставший носильщик: `我要茶。` → `我没有钱。` |
| **2b Чайная** | Доска цен `大杯 五钱 / 小杯 三钱`; хозяйка; три стола; кувшины с надписями `茶` и `水` (одинаковые!); большие и маленькие чашки. |
| **2c Первые небесные ворота (一天门)** | Табличка `一天门`, камень `一人十钱`, привратник. |

**Сценарий:**

- Хозяйка: `你好！你要几杯茶？` — посетители отвечают (сценка при входе):
  - стол 1 (один здоровяк): `一大杯茶！`
  - стол 2 (пара): `两小杯茶。`
  - стол 3 (три монаха): `不要茶。三杯水。`
- Хозяйка вручает поднос. **Головоломка «Поднос»**: выбрать кувшин (茶/水), размер чашки, количество; отнести заказ.
  - Ошибки: `不！我要茶。` / `不！大杯。` / `不！一大杯茶。`
  - Все три стола обслужены → хозяйка `好！谢谢！` и платит `十钱`.
- Носильщик: можно отнести ему чашку чая → `谢谢！谢谢！` (необязательно; он появится позже).
- Привратник: `你好。一人十钱。你有钱吗？` → **ответ** `有` / `有钱` / `我有钱` / `我有`.
  - Денег ≥ 10 → `好。上山！` → глава 3.
  - Денег меньше → `三钱？不！十钱。` (называет вашу сумму по-китайски), нет денег → `你没有钱。`
  - Ответ `没有` → `没有钱，不上山。`

**Страницы:** «Счёт I» 一 二 三 四 五 · «Счёт II» 六 七 八 九 十 · «Чайная» 茶 杯 大 小 钱 · «Торг» 有 没 几 两 人

### Глава 3. 中天门 — «Ворота середины неба» (сумерки → дождь → ночь)

**Знаки (8):** 中 天 门 日 月 云 雨 看

| Сцена | Что есть |
|---|---|
| **3a Средние небесные ворота** | Каменная карта горы (一天门 внизу, 中天门 посередине — «вы здесь», 南天门 наверху); даос у стойки с шестью колоколами; доска `雨 云 月`; монахиня у лестницы. |
| **3b Восемнадцать поворотов (十八盘)** | Ночь, крутые ступени, свет фонаря; надпись на скале `十八`; носильщик. |

**Сценарий (при первом входе в 3a):**

1. Садится солнце. Даос: `看，日下山。`
2. Наползают облака. Паломница: `看！云！`
3. Начинается ливень. Ребёнок: `雨！大雨！`
4. Монахиня у лестницы: `下雨，不上山。`
5. Даос у колоколов: `你看。` (указывает на доску)

**Головоломка «Колокола»:** на колоколах только картинки (солнце, луна, облако, дождь, гора, вода), на доске только знаки `雨 云 月`. Нужно ударить в порядке доски. «Луна» выводится методом исключения. Успех: дождь стихает, выходит луна — даос `好！看，月上山。`, монахиня `好，上山。`

**Страницы:** «Небо» 日 月 云 雨 天 · «Путь» 中 门 看

### Глава 4. 岱顶 — «Вершина» (ночь → рассвет)

**Знаки (10):** 开 出 东 西 南 北 明 休 林 旦

| Сцена | Что есть |
|---|---|
| **4a Южные небесные ворота (南天门)** | Закрытые ворота, привратник в окошке. |
| **4b Небесная улица (天街)** | Геомант с компасом (东 南 西 北); указатель на развилке: 西 ← · 北 ↑ · 东 →. |
| **4c Пик созерцания луны (月观峰, запад)** | Поэт смотрит на заходящую луну. |
| **4d Пик Нефритового императора (玉皇顶, север)** | Стела без надписей (无字碑); старый учёный с табличками. |
| **4e Пик созерцания солнца (日观峰, восток)** | Море облаков, паломники ждут рассвета, алтарный камень с линией горизонта. |

**Сценарий:**

- Клик по воротам: привратник `门不开。` Привратник: `你好。你看日出吗？` → **ответ** `看` / `看日出` / `我看日出` / `我要看日出` → `好！开门！` (ворота открываются).
- Геомант: `南。` (показывает на ворота) → `月下山…西。` (на луну) → `日出…东。` (на восток).
- Поэт: `看，明月！` → `日，月…明！` (пишет на земле: 日 + 月 → 明 — **подсказка о составных знаках**).
- Учёный: `你看。` → **головоломка «Составь знак»**: табличка «человек прислонился к дереву» → 人 + 木 = 休; табличка «два дерева» → 木 + 木 = 林. Затем `好！东，日出。`
- Стела без надписей: игрок может написать на ней свою фразу (сохраняется и показывается в финале).
- Пик солнца: паломники `日出？` · `看东！`. Алтарь: табличка «солнце над горизонтом» → 日 над 一 = **旦 (рассвет)** → восход. Все: `看！日出！` · `日出！` · `好！`
- Финал: «日出 rì chū — восход», статистика подтверждённых знаков, надпись игрока, кнопки «Повторение» и «Новая игра».

**Страницы:** «Стороны света» 东 西 南 北 · «Рассвет» 开 出 明 · составные 休 林 旦 подтверждаются в головоломке.

## 5. Грамматические заметки

| Открывается после | Заметка |
|---|---|
| 吗 | 吗 в конце превращает утверждение в вопрос. |
| 不 + 要 | 不 ставится перед глаголом: 要 — хочу, 不要 — не хочу / не надо. |
| 谢 | 谢谢 — «спасибо»: удвоенный знак «благодарить». |
| 上 + 下 + 山 | Глагол перед местом: 上山 — подниматься на гору, 下山 — спускаться. |
| 有 + 没 | 有 отрицается через 没: 没有. |
| 两 | 二 — при счёте, 两 — перед счётным словом: 两杯茶. |
| 几 + 杯 | 几 — «сколько»; вопрос с 几 обходится без 吗. 杯 — счётное слово. |
| 大 + 小 | Прилагательное — перед словом: 大杯, 小杯. |
| 看 | Нет слова «да»: отвечают повтором глагола — 有。看。 |
| 雨 | 下 — ещё и «падать»: 下雨 — идёт дождь; 日下山 — солнце садится. |
| первый составной знак | Иероглифы строятся из частей: 明 = 日 + 月, 休 = 人 + 木, 林 = 木 + 木, 旦 = 日 + 一. |

## 6. Визуальный стиль

- Плоские слои в духе шаньшуй: дальние горы — бледные, ближние — насыщенные, полосы тумана.
- Палитры по времени суток (день, закат, сумерки, ночь, рассвет).
- Архитектура: красные колонны, изогнутые крыши, каменные арки-ворота с павильоном.
- Персонажи — стилизованные фигуры без лиц (как маски в CoS): соломенная шляпа носильщика, бритая голова монаха, даосский пучок, шапка учёного.
- Шрифты: кайшу (LXGW WenKai) для реплик и дневника — учебное начертание; кисть (Ma Shan Zheng) для вывесок.
- Пиньинь раскрашен по тонам: 1 — красный, 2 — зелёный, 3 — синий, 4 — фиолетовый, нейтральный — серый.
